# PROFILE PHOTO INSTRUCTIONS

To add your custom profile picture to the portfolio:

1. Place your photo file in the `public/` directory:
   - Primary location: `public/profile.jpg`
   - Alternative supported formats: `public/profile.png` or `public/profile.webp`

2. The application automatically detects `public/profile.jpg`, `public/profile.png`, or `public/profile.webp`.

3. If no image is present, a high-tech "ADD PROFILE PHOTO" placeholder frame will display automatically without breaking the interface.

4. Image central configuration can be adjusted in `src/config/portfolio.js`.
